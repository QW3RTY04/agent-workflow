# Public-copy preparation

This is a separate source-only copy of a local workflow project, prepared on November 18, 2026. Its original installation was not edited or reconfigured.

Included: general startup routing, decision state helper, instruction modules, per-task controller/service, activity parser/view, graph renderer, and relevant synthetic tests.

Excluded: personal interview materials and historical manuals, original configuration and bindings, runtime task/consent records, screenshots, logs, databases, generated plugin definitions, local profiles, backups, archives, and original Git history. The legacy interview-specific launcher/profile generator and their three tests are outside this distribution.

Changes: generic interface text; public role-only configuration; relative source-based path resolution; removal of the legacy single-project monitor entry point; optional installer `--build-only` mode for review without installation. Existing model policy and native permission boundaries remain in place.

The generated plugin references the source checkout and Python executable on the installing machine. These generated files are deliberately ignored and must not be uploaded. Installation is opt-in; preparing this copy did not install it.

Before publication, run the tests and review `git diff --cached`. A repository scan checks common credential formats and private filesystem paths, but cannot prove the absence of every secret. Native installation, browser interaction, and live model delegation have not been tested for this copy. No GitHub remote is configured by this preparation.
